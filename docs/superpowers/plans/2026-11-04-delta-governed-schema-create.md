# Governed Schema-only Delta CREATE Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development or superpowers:executing-plans to implement this plan task-by-task using the controller's chosen execution method. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make the initial installed named schema CREATE profile succeed with literal-target Ranger authority and real reservation/native/publication ordering.

**Architecture:** Add a no-op-by-default typed lifecycle to the existing base stage. An issued companion CREATE command supplies reservation-bound authority and a finite initial-empty/log0 metadata continuation, with exact runtime topology measured inside its failing integration. Qualify the resulting route against actual services after the focused tests pass.

**Tech Stack:** Java17, Scala2.12.21, Spark3.5.4/3.5.6, Delta3.3.0/3.3.2, Ranger2.8.0, Gravitino, MinIO, JUnit5, existing Python acceptance harness.

**Spec:** [Governed schema CREATE design](../specs/2026-11-04-delta-governed-schema-create-design.md). Read the public installed-probe findings and native-create findings linked there; execution does not depend on private scouting reports.

## Global Constraints

- Change the Spark Delta base connector and optional Ranger companion only; no Gravitino core/API/server/client/storage-schema change, engine fork, manual native transaction or mutation replay.
- Use Java 17 and Scala 2.12.21; implement first on Spark 3.5.6 / Delta 3.3.2, then qualify Spark 3.5.4 and 3.5.6 × Delta 3.3.0 and 3.3.2 with actual Ranger server/client 2.8.0 and MinIO.
- Consume tableProperties and settings unchanged from spark-connector/v3.5/spark-delta/src/test/resources/native-create/spark-hub-options.json; retain its provenance/hash and effective values, with no writer options or payload write in this schema-only profile.
- Preserve native CDF=true, log retention 45 days, deleted-file retention 364 days, optimizeWrite=true, autoCompact=true and symlink behavior; never disable native work to obtain admission.
- Request CREATE on the literal canonical catalog/schema/table with column=* and owner=null before reserve, before native execution and before publication; USE remains visibility-only and existing-table permissions remain separate.
- Authority must be privately issued, one-shot, bound to immutable intent, exact validated reservation and live session/thread/subject/catalog/settings; no class-name, path-only, ThreadLocal-only or caller-supplied callback authority.
- Preserve separate native and publication outcomes, status-needed uncertainty, terminal cleanup and no automatic retry; never report a postcommit refusal as an uncommitted CREATE.
- Do not add private native interception or new reflective transaction capture; existing qualified metadata validators may be reused unchanged only where their actual inputs are proven compatible.
- This slice qualifies only the initial schema-only profile; ordinary metadata/partition/createIfNotExists profiles remain M2 work, generated date partitions remain M5, and full Spark Hub/M2 support remains open.


## Review Focus

- A denied lookup or hidden reservation is mistaken for a free name: metadata failures propagate, provider conflicts remain authoritative and no unissued route reaches reserve.
- Mutable declarations or copied/foreign carriers reuse authority: immutable intent, exact reservation and single live execution prevent substitution.
- An arbitrary empty-looking RDD gains access: only the measured no-input graph under the private CREATE scope is admitted; unrelated plans remain refused.
- Revocation or a table-specific deny is lost behind schema wildcard coverage: literal-target CREATE checks run at all three operation boundaries.
- Native success is erased by later cleanup/publication/observation failure: preserve CREATE0, publication state, status-needed uncertainty and no replay independently.
