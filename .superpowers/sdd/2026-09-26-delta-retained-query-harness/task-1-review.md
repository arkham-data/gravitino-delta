## Findings

1. **Important — required full driver evidence tests are missing** (`TestDeltaRangerDownloadedQuery.java:39-191`; `TestDeltaRangerRetainedQuery.scala:47-101`). The query tests exercise `nextSequence`, `effective`, parser and recursive freeze, while the Scala test calls `completeCollect` directly with a one-field envelope. No test invokes the driver's PREPARE/COLLECT/RELEASE dispatch or asserts the exact numbered envelopes, `downloads` and `versions` fields, pass-marker schema, 0700 `retained-events` directory, complete command limit behavior, or CLOSE/malformed-input cleanup through the driver. This leaves the main serialized protocol and lifecycle unverified despite Step 8 and the design's offline acceptance requiring those assertions. Add focused tests at the driver/serialization seam that assert these exact records and shutdown behavior without live services.
2. **Important — download coverage does not establish the full required selection matrix** (`TestDeltaRangerDownloadedSecurity.java:47-115,188-278`; `TestDeltaRangerDownloadedQuery.java:77-112`). The new scoped test covers role matching, a later wrong role generation, malformed role bodies, and `NONE` cursor movement. Existing tests cover initial policy/role pairing and some 304/incomplete paths. No assertion binds a post-cursor policy-only or BOTH selection to an applied `Versions` object, or shows the driver requiring both downloads when POLICY is requested but role also advances. The `effective` unit test establishes enum selection only. The implementation appears to make the right selection, but a regression at the driver-to-recorder boundary would evade the focused suite. Add explicit policy/BOTH/effective-union response tests with the applied generation objects.
3. **Minor — exact digest assertion is missing** (`TestDeltaRangerCallbackGateway.java:53-87`). The scoped test checks forwarded bytes and a 64-character digest, but never compares `responseSha256` to the SHA-256 of those bytes. A wrong digest of the correct length would pass while the later live verifier depends on exact digest matching. Assert the computed digest in the gateway and selected-download evidence tests.
4. **Minor — Java fully qualified `Locale` remains in changed code** (`DeltaRangerDownloadedCommand.java:91`; `DeltaRangerDownloadedQuery.java:300,391-392`). The repository instructions prefer a normal `import java.util.Locale`; format/Javadoc checks do not catch this style requirement.

No Critical finding was established. The first two findings are coverage gaps, not claims that the corresponding source behavior is already wrong.
