# Action-validator verification map

This maps the existing dispatch brief and accepted designs to review checks. It
adds no physical/collection enforcement scope. Before final freeze, name the
covering actual test(s) or a concrete unresolved gap for each row in the report.
Existing foundation tests may be reused where the contract is unchanged; new
consumer behavior must have its own actual receipt/binding control.

| Contract | Required component evidence |
| --- | --- |
| Real authority | Actual named wrapper binding and captured receipt; same session and exact retained descriptor/relation/index/log. No replacement table load as action authority. |
| Current registration | PUBLISHED control; missing/pending/replaced incarnation/location/native ID/logical schema rejected. Preserve distinct canonical names and duplicate occurrences. |
| Native compatibility | Retained exact log current-head inspection under real ValidateRetainedBinding; exact raw schema, ordered partitions, protocol and mapping, including logical-schema-preserving mapping change. |
| Version semantics | Data-only advancement between actions passes; regressions and metadata newer than head fail. Before/after native-bracket and first/final whole-action observed drift fail. |
| Finite lifetime | Catalog/metadata/engine closure or expiry rejects, including change during metadata work; no replacement/renewed lease. Metadata identity stays distinct from query user. |
| Complete original access | All original resources across both catalogs authorized before any filter/mask evaluation; duplicate/pruned-away/empty-result obligations retained. Denied access must stop decision reevaluation. |
| Captured decision equality | Exact semantic mask kind/expression and filter presence/expression compared, including NONE and absent decisions. Changed time-dependent decision rejects with unchanged engine publications and access still allowed. |
| One fresh action time | One immutable action Instant for every access/filter/mask request; analysis time is not reused as action time. |
| Complete publications | Policy refresh, same-number publication replacement and role-only changes reject; final stamps checked after metadata callbacks. |
| Subject/configuration | Short user/groups, same session and captured configuration checked before and after work. No configuration changes to manufacture support. |
| Retained original structure | Metadata callbacks cannot mutate the original retained structural payload without rejection; analysis replay and action validation remain distinct. |
| Driver-only authority | Per-action observations cannot become portable authority; no new plan product/serialization/rendering leak, no persistent replacement receipt. |
| Qualified scope | Component method calls only. No installed physical guard, retained collect/collectAsList enforcement, live download or full-Delta claim. |

Final evidence uses a frozen source manifest, original XML, Test.doFirst compiled
inputs, explicit dependency pins and all four requested Spark/Delta pairs with
Ranger2.8/JDK17. Full optional-module regression on the first pair; affected suites
on the other three. Root owns the exact evidence audit and independent review.
