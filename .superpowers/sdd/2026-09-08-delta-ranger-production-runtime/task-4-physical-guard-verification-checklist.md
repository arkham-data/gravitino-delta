# Physical guard acceptance map

Root checklist derived from the existing physical-provenance design and dependent
implementation brief. This adds no new authority or unsupported action surface.
The implementer report must name actual tests/results for each requirement; absence
of a test is not a passing gate. Component tests remain supporting evidence, not
substitutes for installed retained-Dataset collection evidence.

Existing asymmetric broadcast fallback, checkpoint-plus-JSON-tail, no-skipping
mapped/partitioned/two-catalog, empty optimized results and actual native-cache
positives must remain in the final affected regression inventory. Native metadata
validation must not recurse through complete user action validation. Same-session
planning must not share a mutable current-plan slot or strong global plan registry.

Root final gate: independent SPEC and QUALITY verdicts; original behavioral RED;
full module first frozen row plus affected suites on the other three pinned
Spark/Delta pairs; exact test-case multisets where selected identically; all source
and executed compiled artifacts hashed; Ranger2.8 and JDK17 provenance; formatting,
strict Java/Javadoc checks. Preserve failed attempts and distinguish setup failure,
fixture mistakes, supported-boundary rejection and actual regression. No blanket
claims about raw execute/RDD/iterator APIs, running-action cancellation, full native
index serialization, live deployments or full Delta conformance.

Bootstrap refinement from the recorded ruling: actual completed prepared/native
logical output owns a frozen full executable binding. Exact suffix/planner/
pre-columnar manifests qualify before replay; verify sealed original before/after
and compare actual final candidate directly. Unknown/custom rule and strategy
negative controls must observe zero invocations. Copied Prepared evidence with
changed Filter/Project has a behavioral RED. At collection, no expected-plan
replay or user work may occur before admission; inspect actual retained child and
then validate original receipt. Generated native ExprIds/schema copies/functions
need explicit finite correspondence, not omitted fields or class-name equivalence.

Additional integration checks from root rulings: after receipt metadata callbacks,
recheck actual physical child using same witness and a physical-only mutation
negative. Native AQE initialized initialPlan is allowed only with independent
binding and preconstruction extension/cost-evaluator qualification; no execution
for discovery. Qualify exact ordered complete coalesced reducer coverage; reject
unqualified partial/skew/local forms and record their scope.

The installed-child observability ruling supersedes direct real-stock-child
prepare/execute counter wording: require unchanged guard ordering + current
instrumented-child component proof + actual installed collection-entry stack and
user scan/warm-job evidence. Report this composition, never direct counts that
were not measured; zero user work remains required behavior.

Root-link-loss recovery must derive the complete expected executable tree from one
sealed parent authority, not select a logical link by schema/output/head. Require
simple projection/no-skipping positives plus changed expression/source/copied-tag
negatives, duplicate/eliminated original obligations, and reject mixed authorities.
