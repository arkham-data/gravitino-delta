# Task 4: owner continuation with data skipping disabled

Read-only source audit, September 23, 2026, requested against base `993f5a9c9`. Only this document was written. No source/test/Gradle edits, JVM, builds, services, git operations or agents were run. This follows `task-4-native-fallback-scope-audit.md`; its owner protocol and all existing native-ticket requirements remain authoritative.

**A public/protected seam exists. Override `PrepareDeltaScan.prepareDeltaScanWithoutFileSkipping`, call `super` first, then install an owned ordinary non-case `TahoeLogFileIndex` subclass through an explicit receipt-owned preparation transition.** The original registration binding stays attached to its original relation/index; the new index receives derivative preparation authority, not a rewritten registration. The late callback must capture the actual runtime snapshot selected by Delta. It must not pin the scan to the analysis-time descriptor or to a snapshot obtained earlier during preparation.

## Minimal integration

1. Keep the ordinary Ranger-owned `PrepareDeltaScan.apply` and override only its protected no-skipping branch. Invoke `super.prepareDeltaScanWithoutFileSkipping(plan)` before the transition. That preserves Delta's configuration selection and transaction side effect without duplicating `apply` or changing any setting. The existing surrounding typed `PrepareScans` operation must already own the complete original receipt/bindings.
2. For each admitted original `LogicalRelation`, require the exact input index/relation identified by that receipt. Construct the owned subclass using the **primary SnapshotDescriptor constructor**, with the original session, DeltaLog, path, `snapshotAtAnalysis`, `partitionFilters` sequence and time-travel flag unchanged. Keep a private reference to the original index. The output index is necessarily a new object; record this precise original-to-owned transition, including actual relation/descriptor/output occurrence bindings. Never pretend that the new object is the original registration index. Do not infer authority from its equal fields, path or schema. Only the qualified native index implementation can enter this transition; arbitrary subclasses with different behavior do not become trusted by copying their constructor fields.
3. Install that exact owned object as the leaf relation's location. The registration resolver intentionally rejects a different relation/index; do not call it on the transitioned leaf and weaken it to accept the replacement. Resolve/retain the original `BoundRegistrationScan`, and let the preparation transition explain the new leaf to subsequent consumers. Repeated preparation must recognize the same issued transition or fail explicitly, never nest wrappers or create owner authority from an unrecognized prepared object. Keep distinct self-join occurrence obligations even when backing objects are shared.
4. Override `matchingFiles` to enter a fresh invocation derived from the sealed preparation authority, then call `super.matchingFiles` with unchanged argument sequences. Override public `getSnapshot` so, inside that active owned invocation, it calls `super.getSnapshot` exactly once, captures/seals or explicitly rebinds the **returned actual Snapshot**, and returns it unchanged before the superclass file-selection call continues. This preserves `update`, compatibility checks, stored partition filters and Delta's selection behavior. The operation begins before `super.getSnapshot`, because `deltaLog.update` can itself perform native log work. Initial log ownership comes from the exact original registration/preparation owner; exact snapshot RDD ownership is completed once the native getter returns. A failed getter invalidates the invocation.
5. Do not introduce a cached replacement snapshot, call `getSnapshotToScan` directly to bypass `getSnapshot` validation, or freeze the current head merely to simplify capture. If `getSnapshot` is invoked directly through another qualified route, it needs its own bounded owned invocation; the helper must recognize an already active invocation for this exact index and avoid uncontrolled nesting. Incompatible active owners reject. Invocation closing, ticket persistence, exact RDD candidates and cross-thread behavior use the existing typed protocol rather than another framework.

This route preserves exact descriptor and filter identities across preparation and captures actual snapshot identity at selection time. It cannot preserve the original index object's identity while also overriding its methods; the explicit transition is the necessary and reviewable distinction. It changes no initial registration binding and grants no additional time-travel surface.

## Adjacent callback hazards

`inputFiles` needs the same owned bracket around `super.inputFiles`, because scoping only the overridden `getSnapshot` would close before the subsequent native `filesForScan`. Handling the index callback does not broaden the supported user action contract.

`sizeInBytes` can execute snapshot metadata before or after matchingFiles. A minimal public route in the owned subclass is to open the owner invocation, read `deltaLog.unsafeVolatileSnapshot` once, capture/rebind that exact object, then return that object's `sizeInBytes`. This preserves the original single volatile snapshot observation and avoids a race from separately capturing one snapshot then calling `super.sizeInBytes`, which could read another. It does not update or pin the scan snapshot. An alternative is already-sealed provenance proven sufficient for that actual aggregate; merely hoping it is cached is not proof. Statistics work on the **original** registered index before this transition still belongs to the registration/load and logical-preparation native protocol.

The protected Delta statistics accessors are additional call sites to include in the actual-path trace; this audit does not authorize a private-package adapter to invoke them. If a qualified runtime path reaches one outside an owner operation, use a compile-verified legal subclass override/public enclosing seam or report the exact remaining gap. Do not turn `DELTA_STATS_SKIPPING=false` into a silent exclusion.

The inherited case-class `copy` creates a bare base index and loses the continuation. Install the subclass after normal analysis has extracted stored partition filters. Existing named registration requires empty stored filters; preserve that invariant. Do not override copy to mint authority for altered partition filters, and do not reopen path-based reads to test it. Inherited equals/hash are Delta reuse behavior, not provenance. Normal plan clones should retain the actual location reference; explicit index copies require rejection or a separately verified transition. Driver authority stays private, transient and outside the inherited product surface; missing authority fails closed.
